# Test IO Master Hub 🚀

بوابة وأداة تفاعلية متكاملة لمختبري البرمجيات ومستخدمي منصة Test IO، تم تصميمها لتبسيط كتابة تقارير الأخطاء الاحترافية وتدقيق جودتها آلياً ومساعدة المختبرين في مختلف مراحل عملهم.

🔗 **الموقع المباشر:** [https://0xhaxmed.github.io/testio-hub/](https://0xhaxmed.github.io/testio-hub/)

---

## ✨ المميزات الرئيسية للمشروع

1. **🗺️ خارطة طريق متكاملة:** شرح خطوات التسجيل، إعداد الأجهزة، اجتياز الاختبار التأهيلي، والتعامل مع نطاق الاختبار (In-Scope vs Out-of-Scope).
2. **⚡ مولد تقارير الأخطاء (Bug Report Generator):** أداة لتوليد العنوان بالصيغة القياسية المعتمدة وصياغة التقرير كاملاً باللغة الإنجليزية في ثوانٍ.
3. **🤖 الفاحص الآلي للجودة (Automated Quality Auditor):** تدقيق فوري لنص التقرير والتأكد من مطابقة المعايير وإعطاء تقييم رقمي مئوي.
4. **🎥 فاحص مدة الفيديو محلياً (Video Inspector):** فحص مدة وأبعاد ملف الفيديو قبل رفعه للتأكد من توافقه مع مدة الاختبار المثالية (15-45 ثانية).
5. **💵 حاسبة الأرباح التقديرية (Earnings Calculator):** تقدير العوائد الشهرية بناءً على عدد الباجات والتأكيدات السريعة (Reproductions).
6. **🛠️ دليل الأدوات والضرائب:** إرشادات برامج تصوير الشاشة الموصى بها وشرح ملء الاستمارة الضريبية W-8BEN.
7. **✉️ مولد رسائل الاعتراض (Dispute Builder):** صياغة رسائل مهنية لقائد الفريق عند الحاجة لإعادة مراجعة التقرير.
8. **📖 قاموس مصطلحات QA:** محرك بحث سريع لمفاهيم واختصارات فحص البرمجيات.

---

## 💻 التقنيات المستخدمة

- **HTML5 & CSS3** بتصميم عصري داعم للوضع الليلي (Dark Mode) واللغة العربية (RTL).
- **Tailwind CSS** للتنسيق السريع والمتجاوب على شاشات الهواتف والحواسب.
- **Vanilla JavaScript** لتشغيل الأدوات التفاعلية والفحص المباشر محلياً بدون خوادم خارجية.
- **Font Awesome & Google Fonts (Cairo / JetBrains Mono)** لتحسين تجربة القراءة والرموز.

```bash

cd testio-hub
```
